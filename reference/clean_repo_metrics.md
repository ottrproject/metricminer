# Summarizing metrics from GitHub

This is a function to get metrics for all the repositories underneath an
organization

## Usage

``` r
clean_repo_metrics(repo_name, repo_metric_list)
```

## Arguments

- repo_name:

  The repository name. So for
  \`https://github.com/ottrproject/metricminer\`, it would be
  \`metricminer\`

- repo_metric_list:

  a list containing the metrics

## Value

Metrics for a repository on GitHub
